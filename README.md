# 🎂 Happy Birthday Jijaaajii

A surprise birthday website made with HTML, CSS and JavaScript. It is designed to be hosted free using GitHub Pages.

## 1. Add your photos/videos

Put these files inside the `assets` folder:

- `jiju-1.jpg`
- `jiju-2.jpg`
- `jiju-3.jpg`
- `jiju-4.jpg`
- `resort-1.jpg`
- `pool-1.jpg`
- `cake.jpg`
- `pizza.jpg`
- `shake.jpg`
- `video-poster.jpg`
- `birthday-video.mp4`

Keep the filenames exactly the same, or update the filenames in `index.html`.

## 2. Test it

Double-click `index.html` on your computer. The page should open in your browser.

## 3. Put it on GitHub

Create a new GitHub repository, for example:

`birthday-jijaji`

Upload:
- `index.html`
- `style.css`
- `script.js`
- the complete `assets` folder

Then go to:

Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save.

After GitHub finishes publishing, it will give you a public website link.

## 4. Personalise it

The easiest things to edit are:

- Main title: `Happy Birthday Jijaaajii!`
- Hindi/English jokes in the four wish cards
- Birthday messages in the Memory modal
- Resort message
- Treat messages
- Footer message

All of these are in `index.html`.

## 5. Important

Do not upload extremely large videos. For a smooth website, compress the birthday video to a reasonable MP4 size before uploading.

For a private surprise, remember that a GitHub Pages website is publicly accessible to anyone who has the URL. It is not a password-protected private website.
